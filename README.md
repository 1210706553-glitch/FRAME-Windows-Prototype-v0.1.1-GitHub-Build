# 张诗语の米奇妙妙工具

一个面向视频创作者的 Windows 本地执行工具。它不替你剪片，而是把整个视频项目拆成每天 2～5 项可完成的任务，持续显示今天和整个项目还差多少，并用专注流程减少游戏、短视频带来的分心。

## v0.3.0 已完成

- 一次只管理一个当前视频项目，数据仅保存在使用者自己的电脑
- 每个人独立设置称呼、每日开始时间、投入时长、休息方式和发布日期
- 自动把视频制作拆成七个阶段、22 个基础任务
- 每天自动安排 2～5 项，显示今日完成率、项目进度、剩余工时和截止日
- 手动勾选任务、临时补充任务、突出显示唯一“下一步”
- 专注倒计时、完成门槛、15 分钟临时解锁及解锁原因
- 无法制作时必须说明原因；每周首次可作为动态休息，之后记为缺勤并重新排期
- 最近七天完成、专注、休息和缺勤复盘
- 刷新或重启后恢复项目、任务和正在进行的专注计时
- 到设定时间发送 Windows 原生通知；15 分钟未开始再次提醒，之后每 30 分钟跟进
- 专注中、当日任务完成、已登记休息或缺勤时自动停止提醒
- 可选开机自启；关闭主窗口后驻留系统托盘继续待命
- 托盘左键重新打开，托盘菜单可彻底退出
- 设置页可立即发送测试通知并显示权限、自启状态

## 刻意移除

旧版的视频导入、内置播放器、素材时间线、节点标记、转写、Premiere XML、SQLite 项目库和多项目切换已经从 v0.2 主程序删除。这个软件的核心是每日执行，不再内置一个不完整的视频编辑器。

## 后续切片

- Windows 原生应用/网站限制
- DeepSeek 仅参与素材梳理、粗剪和大纲三个阶段
- 系统通知、异常退出恢复和真实 Windows 设备测试

界面会明确标出尚未接通的系统级应用/网站限制，不会把名单设置伪装成已经阻止应用。

## 本地运行

```powershell
npm install
npm run desktop:dev
```

只检查前端：

```powershell
npm run dev
```

## 构建 Windows EXE

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
```

或推送到 GitHub 后，在 **Actions → Build Windows Installer** 下载构建产物 `MickeyToolkit-Windows-EXE`。

## 验证

```powershell
npm run test
npm run lint
npm run build
```

当前数据存放在 WebView2 的本机 localStorage 中，不会自动上传或共享给其他人。
