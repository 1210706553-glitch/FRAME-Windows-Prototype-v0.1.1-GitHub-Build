# 张诗语の米奇妙妙工具

一个面向视频创作者的 Windows 本地执行工具。它不替你剪片，而是把整个视频项目拆成每天 2～5 项可完成的任务，持续显示今天和整个项目还差多少，并用专注流程减少游戏、短视频带来的分心。

## v0.6.0 已完成

- 一次只管理一个当前视频项目，数据仅保存在使用者自己的电脑
- 每个人独立设置称呼、每日开始时间、投入时长、休息方式和发布日期
- 自动把视频制作拆成七个阶段、22 个基础任务
- 每天自动安排 2～5 项，显示今日完成率、项目进度、剩余工时和截止日
- 手动勾选任务、临时补充任务、突出显示唯一“下一步”
- 专注倒计时、完成门槛、15 分钟临时解锁及解锁原因
- 无法制作时必须说明原因；每周首次可作为动态休息，之后记为缺勤并重新排期
- 最近七天完成、专注、休息和缺勤复盘
- 刷新或重启后恢复项目、任务和正在进行的专注计时
- 到设定时间发送 Windows 原生通知；15 分钟未开始再次提醒，之后每 30 分钟跟进
- 专注中、当日任务完成、已登记休息或缺勤时自动停止提醒
- 可选开机自启；关闭主窗口后驻留系统托盘继续待命
- 托盘左键重新打开，托盘菜单可彻底退出
- 设置页可立即发送测试通知并显示权限、自启状态
- 首次设置和设置页的发布日期都提供独立日历按钮与内置月历，同时保留键盘输入
- 每天按设定投入时长尽量排满任务，并自动修复旧版首日任务过少的问题
- 首页显示预计完成日期，以及相对目标发布日期提前或逾期多少天
- 专注开始后自动关闭应用限制名单中的 Windows 程序，并持续阻止重新打开
- 临时解锁15分钟时暂停程序限制，由 Rust 原生计时器在到期后恢复
- 结束专注、登记休息或彻底退出后停止限制，不修改 `hosts`、防火墙或注册表
- 设置页可执行5秒程序限制测试，并显示累计拦截次数
- 系统关键进程、本软件自身、路径和非法进程名会被拒绝
- 设置页可读取当前有窗口的运行软件，勾选后批量加入程序限制名单
- 在“项目计划”页导入 `.srt` 或 `.txt` 字幕，先在本地预览、删改，再决定是否分析
- DeepSeek 一次生成“素材梳理、粗剪规划、视频大纲”三份结果，全部可编辑
- 确认结果后，只替换尚未完成的前三阶段任务；已完成任务和后四阶段保持不变
- 每个人使用自己的 DeepSeek API Key，密钥保存在 Windows 凭据管理器，可更换或清除
- 单文件限制 3 MB、字幕文本限制 300,000 字；不会后台分块或隐藏地产生多次调用
- 启动后在后台检查 GitHub 正式版更新；没有更新或自动检查失败时不打扰
- 发现新版时先显示版本和更新说明，只有用户确认后才下载和安装
- 下载显示真实进度，更新包必须通过 Tauri 签名验证，完成后自动重启
- 专注进行中延后更新提示，结束专注后再询问
- 设置页可查看当前版本并手动检查更新
- 普通 GitHub push 只测试和构建；只有手动运行发布工作流才创建 Release

## 刻意移除

旧版的视频导入、内置播放器、素材时间线、节点标记、转写、Premiere XML、SQLite 项目库和多项目切换已经从 v0.2 主程序删除。这个软件的核心是每日执行，不再内置一个不完整的视频编辑器。

## 本地运行

```powershell
npm install
npm run desktop:dev
```

只检查前端：

```powershell
npm run dev
```

## 构建 Windows EXE

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-windows.ps1
```

或推送到 GitHub 后，在 **Actions → Build Windows Installer** 下载构建产物 `MickeyToolkit-Windows-EXE`。启用更新签名后，构建前必须先配置仓库 Secrets。

## 发布自动更新

首次启用请完整阅读 [`docs/AUTO-UPDATE-RELEASE.md`](docs/AUTO-UPDATE-RELEASE.md)。要点：

1. 仓库必须是 Public，安装后的软件才能匿名读取最新 Release。
2. `TAURI_SIGNING_PRIVATE_KEY` 与 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` 只放 GitHub Actions Secrets，绝不提交源码。
3. 普通 push 不发布。确认构建无误后，到 **Actions → Publish Windows Release → Run workflow** 手动发布。
4. v0.5.0 没有更新器，因此 v0.6.0 需要手动安装一次；之后的新版本才能应用内更新。

## 验证

```powershell
npm run test
npm run lint
npm run build
```

项目、字幕草稿和任务数据存放在 WebView2 的本机 localStorage 中，不会自动上传或共享给其他人。只有用户明确点击“开始一次分析”后，编辑框中的字幕才会发送给 DeepSeek；API Key 由 Windows 凭据管理器保存。
